STORE MANAGEMENT SYSTEM

OOP CONCEPT

1 PRODUCT BLUEPRINT

 1.1 ProductName;
 1.2 Price;
 1.3 Stock

2 METHOD 

 2.1 ADD PRODUCT
 2.2 VIEW PRODUCT
 2.3 UPDATE PRODUCT
 2.4 DELETE PRODUCT
 2.5 EXIT

3 IF THE USER CHOOSES ADD PRODUCT

 3.1 ASK FOR PRODUCT NAME
 3.2 ASK FOR PRODUCT PRICE
 3.3 ASK FOR PRODUCT Stock
 3.4 DYNAMICALLY ALLOCATE A NEW PRODUCT OBJECT
 3.5 DISPLAY "PRODUCT ADDED SUCCESSFULLY"

4 If the user chooses View Products:

 4.1 Check if products exist.
 4.2 Display the details of each product.

5 If the user chooses Update Product:

 5.1 Ask for the product to update.
 5.2 Search for the product.
 5.3 If found, ask for the new information.
 5.4 Update the product.

6 If the user chooses Delete Product:

 6.1 Ask for the product to delete.
 6.2 Search for the product.
 6.3 If found, delete the dynamically allocated object.
 6.4 Remove it from the stored list.

7 If the user chooses Exit:

 7.1 End the program.

8 Repeat the menu until the user chooses Exit.
